Angular is a TypeScript-based frontend framework developed by Google for building Single Page Applications (SPAs). Unlike React, which is mainly a UI library, Angular is a complete framework that includes routing, forms, HTTP client, dependency injection, testing, and state management. It follows a component-based architecture, where each part of the UI is built as a reusable component.

10. Service

A service contains reusable business logic.

Generate

ng g s services/user

user.service.ts

import { Injectable } from '@angular/core';

@Injectable({

providedIn:'root'

})

export class UserService{

getUsers(){

return [

{name:"Hari"},

{name:"Ravi"}

]

}

}

Component

constructor(private userService:UserService){}

users=this.userService.getUsers()
11. Dependency Injection

12. HTTP Client

Component

})

}
